# 分层功能补齐记录（2026-09-28）

## 本轮已实现

| 依赖层 | 后端与 UI 同步补齐 |
|---|---|
| L1 资料处理 | UTF8/GBK 严格解码、非法字节拒绝、保守清除页眉页脚/边缘页码，保留段落和公式；任务显示清理分章阶段 |
| L2 知识结构 | 保存新上传章节原文、多章节归属；五类实体有原文证据；示例/资源须原文引用；补全版本与资料来源签名；revision 事务；类别与章节统计、每章 20 点达标提示、历史补全入口 |
| L3 教师与浏览 | 教师章节编辑、修订保护；原 SVG 图谱复用，图谱/列表/卡片切换，关键词/类别/章节/掌握/缺失内容筛选；图谱导出包含章节和版本 |
| L4 学习导航 | 全部直接先修已掌握的未掌握点才可推荐；按立即解锁后继数量排序；完成/无先修/循环阻塞提示；推荐卡片选目标，标记掌握后刷新 |
| L5 验证准备 | 可复现逻辑与接口检查、原闭环回归，自编双章节样例；浏览器验证卡片和筛选、推荐更新 |

## 实测

- 纯逻辑 9 项、接口 6 项、原闭环 10 项检查通过。脚本与 JSON 结果在 demo 文件夹。
- 真实 MD 上传约 15.1 秒：10 个知识点、11 条关系，五类齐全、两章各 5 点；所有保存的示例/资源均逐字来自原文。
- 此样例只含 10 点，不满足每章至少 20 点的正式样例要求，UI 如实提示。
- 实际验证重复补全不重复写入、教师定义与章节保留、进度更新与学习者/课程隔离。
- TypeScript 检查和生产构建通过；卡片类别/章节筛选和学习推荐经真实浏览器核对。
- 保留“分层功能验收示范”课程供查看；原有离散数学和软件架构课程内容未被补全操作覆盖。

## Prompt 版本

`course-content-v1` 位于 backend/src/course_content.py 的 CONTENT_PROMPT。使用已配置 DeepSeek 模型；限定输入 UID 和五类；类别证据核对原文；示例和资源只保存原文引用，无依据留空。保存版本、来源签名和完成时间。教师修订点整体跳过；新资料来源加入后可补全未修订点。

知识图谱抽取继续复用上游 LLM Graph Builder；本轮新增资料处理、结构补全与业务 UI，没有更换图谱引擎。历史 Chunk 不能可靠恢复章节顺序时标为未分章。

## 正式交付还需完成

1. 至少两门真实课程的充足章节资料，每章至少 20 个有依据知识点；需课程教师审核。程序提供实际计数，不编造节点凑数。
2. 人工标注集核对抽取准确率 ≥70%、问答准确率 ≥75%、解析成功率 ≥95%。功能回归不替代正式准确率验收。
3. 100 点以上图谱、长资料、问答、路径的正式性能测试与报告。当前小样例耗时不能代表所有规模。
4. 最终部署说明、演示视频、测试报告和比赛交付材料与最终数据对齐。
5. 历史章节可在教师编辑页补充，或提供带标题原文重新导入。

本轮补齐 L1–L4 的主要功能缺口，建立 L5 功能验证基础；尚不宣称全部比赛指标已验收。
