# 图谱显示修复

用户已确认修复关系连线并按关系自动布局。继续使用原生 SVG，避免替换整个图谱组件。

修复颜色变量：SVG 和图例直接引用 :root 中实际存在的主题变量，避免 Tailwind 未生成的别名。连线加粗并在节点边界显示方向箭头。默认采用确定性的关系力导向布局；仅将上游初始网格坐标替换为自动布局，保留教师手动坐标。学生拖动位置继续本地保存；提供自动布局按钮清除学生位置，教师自动布局通过现有编辑事务支持保存和撤销。

验收：两个课程均显示与接口数量一致的连线，三种关系有清晰颜色，先修/包含箭头可见，节点文字可读；选择高亮、教师拖动、撤销不受影响。类型检查、构建和浏览器截图通过后交付。

初始坐标识别采取保守规则：只有整图所有坐标均落在上游生成的等距 8–92 网格，且位置无重复时才自动替换；任一非网格位置即保留整图。教师第一次拖动时将全部显示坐标一并写入现有编辑事务，因此重新加载可保留布局。学生位置使用独立本地覆盖，自动布局按钮清除该覆盖。教师点击自动布局将全图新坐标作为一次可撤销事务，保存后持久化。验收按全部接口节点间的全部关系计数，不使用可见区域裁切数量；重载、课程切换和自动布局均检查。
