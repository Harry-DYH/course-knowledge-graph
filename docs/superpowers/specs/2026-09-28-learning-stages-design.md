# 学习路径与基础优先推荐设计

用户强调基础先学、进阶后学且 UI 明显展示。已有目标先修 DFS 与合取先修推荐继续复用，但推荐加入明确先修层级排序，目标路径按层级整理，避免 DFS 某条深分支先于另一基础根。

后端纯函数统一计算有效 PREREQUISITE_OF 的入/出边与 Kahn 层级（无先修为 0，后续点为父层最大值+1）；未入拓扑序的循环及下游点标记待修正，不作为可靠阶段。推荐仅限未掌握、全部直接先修已掌握的合法点，按层级升序、未掌握后继覆盖数降序、立即解锁数降序、名称稳定排序。计算后继覆盖去重；覆盖不是立即解锁。明确区分根基程度（结构依据）与主观难度，零先修图不伪称阶段可靠。

返回推荐理由、层级、缺失先修、可立即解锁点和所有阶段点的掌握/可学/待先修状态。阶段标题：第0层基础起点，第1层知识衔接，第2层及以上逐步进阶，层级原值展示。循环点单独标为关系待修正。目标路径保持全部未掌握先修，但按稳定层级排序，标记当前可学/需要先完成的先修。已掌握目标保持原完成响应；循环仍返回409。

UI 升级 NextLearning 为显眼的基础→衔接→进阶总览、首要推荐及理由、立即解锁内容、完整可点击阶段清单。推荐/阶段点点击“查看学习路线”直接计算目标路径，无需再按第二个计算按钮。目标结果按阶段分组，当前可学与待先修显式不同；知识点目标详情可查看。掌握后刷新推荐和当前路径，计算中按钮禁用，保留真实后端进度和圆形图谱风格。

验收：多分支目标路径基础先于进阶，AND先修，层级比解锁收益优先，未掌握后继去重，零边/空图/环/完成、课程与学习者隔离。原接口响应兼容添加字段，原闭环回归；两真实课程接口及浏览器 UI 展示/选择路线/进度刷新验证。只改算法和 UI，不篡改课程知识或用户进度。
