# 比赛核心功能补齐

用户授权：核对比赛要求，直接实现可独立完成的功能，整理需要用户介入的事项。

## 方案

保留原资料上传、抽取、原图预览、向量检索。新增中文课程工作台 `/courses`，提供教师和学生两个操作视图。相比直接修改原图属性面板，这种方式能集中提供课程管理、编辑和学习导航；相比重写整个上传系统，复用原项目能较快完成联调。

课程关联多个已抽取完成的原始 Document。导入时复制实体和关系为课程专属 CoursePoint/CourseLink，保留原实体 ID、资料名和片段引用。不同课程即使概念名称相同也不共享可编辑实体。已有课程的再次导入保留教师编辑和学习状态，导入新实体与缺失关系，不覆盖人工修订。原始图谱保持抽取证据用途。

教师可建课、关联已完成资料，增改删知识点与三类知识关系，编辑定义、类别、例子、资源和难度。删除知识点连带移除该课程关系与进度，界面确认明确影响；不删除原始资料。编辑先修关系时验证不产生环，旧图存在环时路径计算提示具体阻塞。

学生通过本地学习者标识保存掌握状态；这是演示身份而非正式账户鉴权。针对目标知识点收集未掌握先修点并进行拓扑排序，给出先修关系依据、学习顺序和路径展示；已掌握的点不重复推荐。无先修证据必须明确提示，不能将字母顺序解释为教学依据。

问答仅检索当前课程关联资料，固定 vector 模式。附加当前课程已修订知识点和关系到问答上下文，保留来源和教师编辑标识，以避免页面修订与回答脱节。手动新增的知识只引用课程教师修订来源，不伪装成文档原文。问答流程调用现有向量检索，课程编辑内容需要明确成为受信任课程内容而非系统命令。

## 验证

验证两课程隔离、导入幂等、教师增改删、先修方向及环检测、学习进度跨刷新保存、路径排序和资料限定问答。至少验证 TXT 与 DOCX 上传解析；用自编第二门课样例演示双课程。记录实测时间、测试资料性质和准确率评估边界。

## 用户介入

真实课程资料及使用权限；抽取准确率人工标注；正式答辩团队/学校信息；最终视频/PPT提交规格与外部部署。自编样例自动测试不替代真实章节人工准确率。账号鉴权不属于本轮比赛最小演示闭环。
