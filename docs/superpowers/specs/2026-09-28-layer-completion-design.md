# 按层补齐课程功能

用户已授权按完成度报告逐层补齐，UI 同步实现。沿用当前 FastAPI、Neo4j 和 React 工作台。

L1/L2：严格解码 UTF8/GBK，保留公式与段落，识别中文章节和 Markdown 标题，重复页眉页脚仅保守处理。新上传在抽取前保存文档章节原文，历史资料从已有 Chunk 恢复并提供补全按钮。没有标题明确显示未分章，不编造章节。章节归属以知识点名称在章节原文中的匹配为依据，允许多章节；每章实际计数，不强造二十点。

补全以模型对原文进行五类实体分类和定义/例子/资源提取。结构化输出只可使用已存在知识点 ID；类型必须有原文证据，例子和资源要求原文原句，无依据留空。缺失字段不会伪造。记录 Prompt 版本与补全状态。已有教师修订整体跳过，图谱更新使用 revision 事务，失败可重试，导入幂等。

L3：知识地图增加图谱、列表、卡片切换，以及章节/类别/关键词过滤、数量与缺失信息提示；节点详情和教师编辑同步章节；过滤图谱只显示两端均在结果中的关系。历史资料补全入口位于教师页；不自动后台覆盖旧课程。

L4：补无目标时下一步可学点推荐，以全部先修已掌握为资格，按解锁后续点数量排序并解释依据；并列按名称，仅作为稳定显示顺序。区分已全部掌握、图谱缺少先修与先修环阻塞。保留目标 DFS 路径。UI 推荐卡片可查看详情、设为目标、标记掌握，进度改变后刷新推荐。

L5：本轮维护可复现功能验收和 Prompt 记录，执行 UTF8/GBK、两章节/五类别原文样例导入、补全幂等/教师保护、列表过滤、下一步推荐与课程隔离回归。人工准确率与比赛材料不伪称完成。先基础单元校验，再真实 API 样例与 UI 截图；数据只操作自编样例，保留原课程。

幂等键为课程+原实体 origin_id，章节键为课程+资料名+标题序号，补全版本为固定 Prompt 版本；已补全点跳过，教师 edited 标识点整体跳过。补全读取 revision，写入事务比较 revision，冲突返回409且整批回滚。重复补全不得增加章节、点、关系。

章节匹配忽略空白与大小写，保留标点以减少误匹配；同名多章保留归属列表。未匹配显示未分章；历史 Chunk 若不能确认原始顺序，不恢复标题顺序，一律显示未分章，待新上传或教师更正。证据只取当前课程关联文档；未知ID拒绝，证据、例子、资源原句由服务端比对对应原文，不通过不得写入。

先修方向 A→B 表示先学A后学B。候选为未掌握且全部直接先修已掌握的点。解锁数为掌握候选后立即符合资格的直接后继数。例如 A→C、B→C、A→D，初始候选A/B，A解锁D故排前；掌握A后候选B/D，B解锁C故排前；全部掌握后返回完成。合法无先修点允许推荐；全图零先修边提示依据不足；未掌握点存在但候选为空时说明先修阻塞并给出环检测结果。
