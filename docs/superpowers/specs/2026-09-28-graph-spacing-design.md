# 图谱拥挤修复设计

用户指出离散数学和软件架构基础关系图拥挤，按既有授权直接修复。保留原生 SVG、节点与关系数据、教师手动位置。将自动布局改为按先修关系的拓扑层次从上到下排列，以重心排序减少交叉；层内拥挤时分行，位置确定且避免标签盒重叠。无先修边时使用包含关系，遇环安全降级不无限循环。自动布局仅替换未修改的初始网格与学生旧自动缓存；教师自定义位置不覆盖。

节点改为有边界的圆角卡片，长名称在卡片内两行显示，次级信息只显示类别，完整名称/章节置于 title/详情。关系保持三种颜色和方向；同对节点多种关系使用不同曲线，端点在卡片边缘，搜索/拖动/缩放/路径高亮继续有效。知识地图未选择点时使用全宽，选择点后详情放在图谱下方；教师编辑保留侧栏。

验收针对两门真实课程：全量节点与关系保持，先修层序正确、自动布局节点盒不重叠、平行关系路径不同、无环/环/空图可运行；类型检查和构建；实际浏览器截图验证两门课程并检查选择/筛选/布局刷新。只改视觉布局，不更改课程数据库。
