# 知源 UI 复用与接入结果

参考文件：工作区 `meoo_zip_1790438253577.zip`。源码解压到 `ui-reference`，原压缩包未改动。

## 结论

React + Vite 技术兼容。新 UI 作为独立项目运行在 http://127.0.0.1:3015/，连接现有 FastAPI、Neo4j 和 DeepSeek；原图谱构建器仍在 http://127.0.0.1:8080/ 供调试。新 UI 保留原设计的教师、学生页面布局和图谱画布，替换了原来只读本地模拟数据的业务页面。

## 已接通

| 功能 | 当前状态 |
| --- | --- |
| 多课程 | 数据库存储课程与资料归属；两个样例课程已创建，图谱相互隔离 |
| 资料上传 | 支持 PDF、DOCX、TXT、MD，上传后调用真实抽取并导入当前课程 |
| 图谱 | 从资料抽取知识点和三类关系；画布支持缩放、拖动、搜索和详情 |
| 教师编辑 | 增删知识点、关系，编辑定义、例子和资源；保存到 Neo4j；版本冲突提示；删除的原始知识点和关系不会在后续导入中自动恢复 |
| 学习导航 | 学生掌握状态持久化；从先修关系计算目标学习路径，过滤已掌握项 |
| 课程问答 | 只检索当前课程资料，调用 DeepSeek，展示资料出处与真实耗时；问题明确涉及已修订知识点时优先使用教师修订内容 |
| 一键启动 | 启动数据库、后端、原调试页和新 UI，默认打开新 UI |

## 尚未达到的比赛交付项

当前两门课使用自写的小样例，不能作为真实课程准确率证据。真实资料需人工标注后测抽取准确率、问答正确率、百节点交互性能和连续运行稳定性。上传已记录真实处理阶段及耗时，并支持失败重试；后端没有逐阶段百分比。教师与学生入口没有正式账户登录及角色权限。教师定义和相关关系修订已用于问答优先上下文；大量同义问题和复杂关系推理仍需评测。原 UI 的随机置信度和模拟耗时已移除，固定自测题已替换为依据当前课程图谱生成并评分的自测。

后续补齐了出处片段、节点原文、编辑撤销/重做与未保存保护、图谱 JSON 导出、课程改名、自测记录与课程统计。闭环 10 项接口检查已通过，详细结果见 `闭环与功能完成情况.md`。

## 用户需要提供

真实课程资料及使用授权、人工核对的知识点和问答标准答案、团队及比赛提交信息。系统可以据此形成准确率报告、案例截图、演示视频和答辩材料。
