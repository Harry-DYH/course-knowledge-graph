# 最小闭环验收

## 网页操作

1. 双击工作区“启动课程知识图谱.cmd”，进入 <http://127.0.0.1:3015/>。
2. 选择“离散数学”或“软件架构基础”。在新建课程中可关联已经抽取的样例，或上传不同文件名的 TXT、DOCX、MD。
3. 在教师编辑页选知识点，核对原文片段，修改定义/例子或关系并保存；刷新后核对保存结果。
4. 测试新增节点、撤销、重做、导出；未保存时切换课程应有提示，完全撤销回原图后不应提示未保存。
5. 在学生学习路径页选目标，计算先修顺序，标记掌握后确认路径过滤已掌握项；刷新确认进度。
6. 在课程问答页提问，核对答案、资料文件名和原文片段；教师已修订的定义及关系应优先。
7. 在知识自测页完成五道题，查看分数、反馈及最近成绩。

## 问答参考

| 离散数学问题 | 资料依据 |
| --- | --- |
| 什么是集合？ | 确定对象构成的整体；例子 A={1,2,3} |
| 等价关系满足哪些性质？ | 自反、对称、传递 |
| 学习等价类之前需要什么？ | 等价关系及其相关先修点 |
| Dijkstra 算法复杂度是多少？ | 样例没有提供，应明确无法依据资料回答 |

## 自动接口检查

服务已启动且 DOCX 样例已经抽取后，在项目目录运行 `python demo/verify_loop.py`。脚本建立临时课程，验证课程/学习者隔离、图谱保存和校验、教师关系优先问答、自测和模拟失败恢复，最后清理临时课程。结果写入 `闭环实测结果.json`。

这些验收使用自编小样例，验证功能流程与数据规则，不替代真实课程人工准确率、性能和稳定性报告。
